CONSTRAINTS

WHAT IS CONSTRAINT?
A Rule that controls what kind of data can be stored in a table
we have different types pf contraints:
primary key
Not Null
Unique
Check
Default
Foreign Key 

EXAMPLE:
create table employee_details(
            emp_id INT PRIMARY KEY,
            emp_name Varchar(20) NOT NULL,
            email varchar (50) UNIQUE,   
            age INT check (age>=18),
            sal INT DEFAULT 25000);
